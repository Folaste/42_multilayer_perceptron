# 42 Multilayer Perceptron

A compact educational implementation of a multilayer perceptron (MLP) created for the 42 school project. This repository contains a small neural network implementation meant for learning and experimentation: feedforward, backpropagation, configurable layer sizes, and simple training/evaluation utilities.

## Features
- Feedforward and backpropagation training loop
- Configurable network architecture (number of layers and neurons)
- Common activation functions (sigmoid, ReLU, softmax)
- Simple dataset loading (CSV/plain formats) and evaluation metrics
- Minimal, readable code intended for learning and extension

## Requirements
- A compatible compiler/interpreter for the repo's language (check the codebase) — common examples:
  - Python 3.10+
- A terminal / shell environment
- (Optional) datasets in CSV format for training/testing

## Quickstart
1. Inspect the repository layout and choose the entry point (see Project structure).

2. Install requirements (venv is recommended)
   ```
   python install -r requirements.txt
   ```

3. Launch the project (-h for help)
   ```
   python main.py ...
   ```

## Project structure
- src/        — source code for the network
- data/       — sample datasets
- models/     — saved network models
- README.md   — this file
